# Instrukcja szybkiego wdrożenia wizytówki na Facebooka

1. **Wgraj pliki na serwer lub hosting**
   - Skopiuj pliki `index.html`, `styles.css` oraz folder `img/team` (zawiera zdjęcie) na swój serwer lub hosting (np. Netlify, Vercel, GitHub Pages, cba.pl, home.pl).
   - Jeśli nie masz własnego hostingu, możesz użyć darmowego Netlify lub Vercel – wystarczy przeciągnąć pliki przez przeglądarkę.

2. **Uzyskaj link do strony**
   - Po wdrożeniu otrzymasz adres URL (np. `https://twojanazwa.netlify.app` lub `https://twojanazwa.vercel.app`).

3. **Wstaw link na Facebooka**
   - Skopiuj adres URL swojej strony.
   - Wklej go w poście, komentarzu lub w sekcji "O mnie" na Facebooku.
   - Facebook automatycznie pobierze tytuł, opis i zdjęcie z Twojej wizytówki.

4. **Dodatkowe wskazówki**
   - Jeśli chcesz, aby Facebook wyświetlał inne zdjęcie lub opis, edytuj odpowiednie meta tagi w pliku `index.html`.
   - Możesz dodać przycisk do Messengera lub inne linki społecznościowe w sekcji Kontakt.
